手書き配車表の記入例とExcelでの作り方

運送会社の手書き配車表は、日付・車両・担当者・積地と卸地・予定時刻を、1便につき1行で記録すると確認しやすくなります。このページでは、紙で書く場合とExcelで入力する場合に共通して使える項目・記入例から、表の作り方を説明します。

日々の配車予定を整理する社内管理表の例です。運行指示書などの法令帳票として必要な項目を網羅するものではありません。

手書き配車表の記入例：1便を1行にまとめる

紙でもExcelでも、同じ車両が午前と午後に別の便を担当する場合は、2行に分けて記録します。以下は運送会社向けの架空の記入例です。氏名・経路・金額は説明用で、商品の実画面ではありません。

運行日車両担当者積地 → 卸地予定時刻売上
2026/10/121001山田（例）川口 → 横浜08:00 → 10:0035,000円
2026/10/121001山田（例）横浜 → 川口13:00 → 15:0030,000円

この例の売上合計は65,000円です。予定の変更は該当する行を更新し、予定時刻と実績時刻を管理したい場合は別の列を用意します。積込・荷下ろしの予約時刻を記録する会社では、出発・到着時刻と区別して項目名を決めてください。

紙に手書きして使う場合

  • 用紙の上部に日付と更新担当者を記入し、同じ日の表を何枚も並行して更新しないようにします。
  • 行間と備考欄を広めに取り、変更時刻・変更内容を追記できるようにします。
  • 変更があった便は、車両・担当者・積地と卸地・時刻をまとめて再確認し、関係者へ伝えます。
  • 自作したExcelの表を印刷して使う場合は、印刷範囲・用紙の向き・拡大縮小を設定し、文字が読める大きさか印刷プレビューで確認します。

紙の表を撮影・配布する運用では、更新前の画像と最新版を取り違えないよう、更新日時を付けて共有してください。

移行前に決めておく入力ルール

  • 1行の単位を「1運行」などに統一する
  • 車両番号の先頭ゼロを残す場合は、入力前に文字列形式を設定する
  • 日付や時刻を文字列と混在させず、表示形式をそろえる
  • 運行状況の呼び方と、予定変更を入力する担当者を決める
  • 原本とバックアップの保存先を決め、誤って上書きしないようにする

Excelの配車表は情報を整理するための表です。運行時間の適法性や車両・担当者の重複を自動で判定する機能があるとは限りません。配車確定前の確認は別途行ってください。

1. Excelの配車表に必要な項目を決める

まず、現在使っている紙の配車表から必要な情報を洗い出します。業務によって必要項目は異なりますが、次の項目が出発点になります。

項目記入例用途
運行日2026/10/10日付別に管理
車両番号1001使用車両を特定
ドライバー山田担当者を確認
積地・卸地川口・横浜運行経路を把握
出発・到着時刻08:00・10:00運行予定を把握
運行状況予定・運行中・完了進捗を確認
売上65,000円運行別の売上を整理

2. Excelに見出しと入力欄を作る

1行目に見出しを設定し、2行目以降に運行情報を入力します。1行を1運行に統一すると、後からフィルターや集計を使いやすくなります。

入力ミスを減らす工夫

  • 運行状況は「予定・運行中・完了」などの選択式にする
  • 日付・時刻・金額の表示形式をそろえる
  • 車両番号やドライバー名は台帳と表記を統一する
  • 見出し行を固定し、フィルターを設定する

3. 売上や経費は別表で整理する

配車表にすべての情報を詰め込むと見づらくなります。運行別の売上、燃料費、高速料金などは必要に応じて別シートに分け、運行番号などの共通キーで照合できるようにしましょう。

売上から登録経費を差し引いた金額は、その管理表に含めた費用の範囲の収支です。ただし、人件費や固定費などを含むかによって計算結果は異なるため、社内で定義を統一してください。

4. 手書きからExcelへ移す最初の1週間

  1. 現在の紙の項目とExcelの列を照合し、車両・担当者の表記をそろえます。
  2. まず1日分を入力し、便の抜けや重複、時刻の取り違えがないか紙と照合します。
  3. 1週間を目安に運用を試し、変更を誰がいつ反映するか確認します。
  4. 紙とExcelを併用する間は、どちらを最新版とするか決めます。複数人で編集する場合は保存先と競合時の扱いも確認します。

紙の情報は自分で転記する必要があります。業務管理PROに紙の自動読み取り・自動取り込み機能はありません。

配車表のExcelテンプレートを選ぶときの確認項目

「配車表 エクセル テンプレート」を探している場合は、配送予定を記録するだけで足りるか、車両台帳・運転日報・売上管理表も必要かを先に決めましょう。ここでいう配車表は予定を一覧にする社内管理表です。

  • 同じ車両が複数便を担当する場合に、便ごとに記入できるか。
  • 配送先と出発・到着予定の時刻が、自社で使う情報と合うか。
  • 売上・経費も管理する場合に、金額の入力先と集計範囲が明確か。
  • Excel環境、価格、入力方法、対応しない機能を購入前に確認できるか。

このページは作り方と記入例の解説です。業務管理PROは2,980円の買い切り商品で、無料の配車表ファイルは配布していません。有料テンプレートの実際の入力項目を見ることで、必要な範囲を比較できます。

よくある質問

手書き用の配車表や無料Excelファイルをダウンロードできますか？

このページには記入例と自作の手順を掲載しています。配布用の無料ファイルや業務管理PROの無料版はありません。商品は2,980円の買い切りです。

Excelだけで配車表は作れますか？

はい。基本的な配車表はExcelの表、フィルター、入力規則などで作成できます。

Excelで配車管理をするときの注意点は？

入力ルール、更新担当、バックアップ、同時編集時の競合防止を決めておくことが大切です。

手書き配車表を自動でExcelに変換できますか？

Excelの表を作るだけでは自動変換されません。紙の情報を移す作業や、別途読み取りの仕組みが必要です。
